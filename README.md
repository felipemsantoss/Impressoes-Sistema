# Impressões do Sistema em DOMPDF (Adianti)

Projeto desenvolvido para geração de impressões em PDF utilizando **DOMPDF** integrado ao framework **Adianti**.

## 📌 Descrição

Este projeto tem como objetivo gerar documentos e relatórios em formato PDF a partir de páginas HTML, permitindo personalização de layouts, tabelas, assinaturas, cabeçalhos e rodapés.

## 🚀 Tecnologias Utilizadas

- PHP
- Framework Adianti
- DOMPDF
- HTML5
- CSS3

## 📂 Estrutura

O projeto contém templates HTML utilizados para geração de documentos em PDF, com foco em:

- Ordens de serviço
- Relatórios
- Termos
- Formulários personalizados
- Impressões em formato A4

## ▶️ Como utilizar

1° Abra o Sistema (na base que precisa modificar)
2° Entre no módulo de impressão
3° Configure a impressão
